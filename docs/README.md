# DevAI Web App (GitHub Pages root)

This folder is served live at https://enestrupi.github.io/DevAI/
(GitHub Pages natively publishes a `/docs` folder on the main branch.)

Authoritative source lives in `/site/` in the repo; the two are kept in sync.
Run locally:
```bash
python3 -m http.server 8080   # inside this folder
```
