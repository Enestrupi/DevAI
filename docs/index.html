🔌 Connect Roblox Studio

Pair Studio with DevAI to send scripts directly into your game — no servers, no Python.

1

Install Plugin

Download DevAI-v6.zip, extract, run install-devai.bat — or drop DevAI.plugin.lua into your Plugins folder.

2

Open Studio

Launch Roblox Studio and open any place.

3

Open Plugin

Plugins tab → click DevAI. The Lemonade Studio Bridge panel opens.

4

Pair

Click "Generate New Code" below, then press the ↻ Refresh button in the plugin. It picks up the code automatically.

5

You're live

Green dot appears top-right. Every "Send to Studio" inserts instantly.
