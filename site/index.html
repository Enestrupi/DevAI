⚔ DevAI

Browser-based AI co-developer for Roblox — chat, generate 3D meshes, thumbnails, GUIs, animations, and Luau. All in one place, no Studio plugin required (though there's one if you want it).

Quick start

  1. Open ⚙ Settings and paste an OpenRouter key (free from openrouter.ai/keys). This powers chat, code, GUI, and thumbnails.
  2. (Optional) Paste a Meshy key from meshy.ai/settings/api for 3D model generation. 200 free credits/month, no credit card.
  3. Use the tabs above to build what you need. Copy Luau code into Studio, or download GLB/PNG files and drag them into your place.

What's in each tab

  • 💬 Chat — Roblox-specialized AI assistant. Luau-aware, knows services/Remotes/DataStores.
  • 🧊 3D Models — Text → GLB/FBX mesh (Meshy). Preview in 3D, download, rig with walk/run.
  • 🖼 Thumbnails — Generate Roblox thumbnails/icons with character/set prompts.
  • 🎨 GUI — Describe a menu/HUD/shop → get a Luau LocalScript that builds it.
  • 📜 Luau Code — Focused code generation (pick Script/LocalScript/ModuleScript, target service).
  • 💃 Animations — Generate AnimationController scripts + list of IDs; rig humanoids from Meshy.
  • 🔌 Studio Sync — Session code to pair with the DevAI Roblox plugin (future auto-sync).
